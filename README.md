
# Clinical Trial Repeated-Measures ANOVA and Biomedical Text Mining

## Overview
This repository contains a combined analytical project involving:
1) Statistical analysis of clinical trial data using a one-way repeated-measures ANOVA.
2) Biomedical text mining of online health discussions using web scraping and transformer-based NLP models.

## Project Components
- **Clinical Trial Analysis**: Evaluation of fasting blood glucose changes over time in a Phase II study using repeated-measures ANOVA, including effect size estimation and sphericity corrections.
- **Biomedical NLP**: Web scraping of medical discussion posts, sentiment analysis of user comments using DistilBERT, and biomedical named entity recognition using BioBERT.

## Methods and Tools
- Statistical analysis: repeated-measures ANOVA
- Web scraping: `rvest`
- NLP: DistilBERT (sentiment analysis), BioBERT (biomedical NER)
- R–Python integration via `reticulate`
